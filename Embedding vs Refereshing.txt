TASK 1: EMBEDDING vs REFERENCING
=====================================================================

REM EMBEDDING   : related data stored INSIDE the same document (denormalized).
REM REFERENCING : related data stored in a SEPARATE collection, linked by an _id (normalized).
REM
REM Embed when:                          Reference when:
REM   - data is read together               - data is large or grows without limit
REM   - "contains" / "has a" relationship   - data is shared by many documents
REM   - child has no meaning on its own     - child is queried/updated on its own
REM   - child list is small and bounded     - document would approach the 16 MB limit

----- 1.1 EMBEDDED design: student with address inside -----

----- 1.8 Quick decision table I wrote -----

REM  Question                                  Embed       Reference
REM  Read together almost always?              YES
REM  Child list small & bounded?                YES
REM  Child list unbounded / very large?                      YES
REM  Same child shared by many parents?                      YES
REM  Child updated independently, often?                     YES
REM  Need atomic update of parent+child?       YES
